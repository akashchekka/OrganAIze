Describe a goal. OrganAIze spawns specialist agents, coordinates them, and delivers the result.

Features

Self-Organizing

Agents assess cognitive load and spawn specialists on their own. No pre-defined workflows.

Recursive Spawning

Agents spawn sub-agents with depth limits, budget halving, and global caps.

Direct Output Flow

Child agents return results directly to their parent via tool messages. No shared memory needed — outputs flow up the tree.

Zero Dependencies

No databases. No Redis. No MongoDB. Pure in-memory execution with file-based session output.

Cost Transparency

Every LLM call tracked per-agent with session-wide token caps. Full breakdown in session.json.

Provider-Agnostic

Works with OpenAI, Azure, Anthropic, Ollama. Switch providers with one env variable.

How It Works

1

Provide a goal

Any complex task. Building an app, researching a topic, analyzing data.

2

Decompose

Genesis agent scores breadth, depth, parallelism. Spawns specialists if needed.

3

Execute

Each agent runs independently with its own tools, persona, and state.

4

Synthesize

Outputs collected, merged, and delivered as one cohesive result.

Safety and Control

  • Tool allowlists per agent blueprint. No privilege escalation.
  • Session-wide token cap. All agents halt when budget is exhausted.
  • Depth limit, budget halving, global agent cap. No runaway spawning.
  • Restricted tools blocked below configurable depth. Defense in depth.
  • State checkpointed at every graph transition via LangGraph MemorySaver.
